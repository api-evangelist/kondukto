## API Reference
- [Starting with Kondukto API](https://docs.kondukto.io/reference/starting-with-kondukto-api.md)
- [Get API Token via UI](https://docs.kondukto.io/reference/get-api-token-via-ui.md)
- [Health Check](https://docs.kondukto.io/reference/health-check.md): Api health check
- [Get Users](https://docs.kondukto.io/reference/get-users.md): Return users. Query users by username or email
- [Get User Details](https://docs.kondukto.io/reference/get-user-details.md): Returns a user's details
- [Get Teams](https://docs.kondukto.io/reference/get-teams.md): Return teams. Query teams by team name.
- [Get Teams With Members](https://docs.kondukto.io/reference/get-teams-with-members.md): Returns teams with members. Query teams by team name.
- [Get Team Details](https://docs.kondukto.io/reference/get-team-details.md): Returns a team's details
- [Get Team Members](https://docs.kondukto.io/reference/get-team-members.md): Returns a team's members
- [Create a Team](https://docs.kondukto.io/reference/create-a-team.md): Create a team through API
- [Update a Team](https://docs.kondukto.io/reference/update-a-team.md): Update a team through API
- [Delete a Team](https://docs.kondukto.io/reference/delete-a-team.md): Delete a team by id
- [Update Team Members](https://docs.kondukto.io/reference/update-team-members.md): Update members of a team
- [Get Labels](https://docs.kondukto.io/reference/get-labels.md): Return labels. Query labels by label name.
- [Create Label](https://docs.kondukto.io/reference/create-label.md): Create a label
- [Delete Label](https://docs.kondukto.io/reference/delete-label.md): Delete a label by ID
- [Get Business Unit Tags](https://docs.kondukto.io/reference/get-business-unit-tags.md): Return business unit tags. Query business unit tags by business unit tag name.
- [Create a Product](https://docs.kondukto.io/reference/create-a-product.md): This endpoint lets you create a new product. The product name should be unique and should not contain any spaces.
- [Update a Product](https://docs.kondukto.io/reference/update-a-product.md): Overwrites the projects of a product by the given values.
- [Get Products](https://docs.kondukto.io/reference/get-products.md): Returns the list of products.
- [Get Product Details](https://docs.kondukto.io/reference/get-a-product-details.md): Returns the details of a product.
- [Create a Project](https://docs.kondukto.io/reference/create-a-project.md): This endpoint lets you create a project with the given parameters. To create a project on Kondukto, you can use ALM (Application Lifecycle Management) URL or ALM ID.  The ALM ID or the ALM URL can be easily retrieved from the CI/CD tools.
- [Update a Project](https://docs.kondukto.io/reference/update-a-project.md): This endpoint lets you update a project with the given parameters.
- [Get Project List](https://docs.kondukto.io/reference/get-project-list.md): This endpoint returns project list in a paginated format.
- [Check if ALM Project exists on Kondukto](https://docs.kondukto.io/reference/check-alm-if-it-exists.md): This endpoint checks if an ALM project has been created on Kondukto
- [Get Project Detail](https://docs.kondukto.io/reference/get-project-detail.md): This endpoint returns details of a specific project.
- [Get Project Scans](https://docs.kondukto.io/reference/get-project-scans.md): This endpoint retrieves scans of the given project.
- [Project Security Criteria Status](https://docs.kondukto.io/reference/project-security-criteria-status.md): This endpoint retrieves security creteria of the specific project.
- [Get Project Vulnerabilities](https://docs.kondukto.io/reference/get-project-vulnerabilities.md): This endpoint retrieves vulnerabilities of the specific project.
- [Create Project Scan Configuration](https://docs.kondukto.io/reference/create-project-scan-configuration.md): This endpoint creates a scan parameter to project.
- [Get Project Scan Configuration](https://docs.kondukto.io/reference/get-project-scan-configuration.md): This endpoint retrieves security creteria of the specific project.
- [Create New Scan](https://docs.kondukto.io/reference/create-new-scan.md): This endpoint allows you to create a new scan with specified parameters for a project. You can access the "custom" information in the body parameters from the Scanner details.
- [Image Scan](https://docs.kondukto.io/reference/image-scan.md): This endpoint allows you to create a new scan for a container image with specified parameters for a project. The scan details and configurations are included in the request body.
- [Import Scan Result](https://docs.kondukto.io/reference/import-scan-result.md): This endpoint allows you to import scan results for a specified project. The scan details and configurations are included in the form parameters.
- [Restart A Scan](https://docs.kondukto.io/reference/restart-a-scan.md): This endpoint creates a scan event on Kondukto. To trigger a scan, the project should exist on Kondukto, and the scanner should be already configured.
- [Get Scan Details](https://docs.kondukto.io/reference/get-scan-detail.md): This endpoint returns scan details of the given scan.
- [Get Scan Security Criteria](https://docs.kondukto.io/reference/get-scan-release-status.md): This endpoint returns the security criteria of a specific scan.
- [Get Scans in the Queue](https://docs.kondukto.io/reference/get-scans-in-the-queue.md): This endpoint returns scans in the queue.
- [Get Completed Scans](https://docs.kondukto.io/reference/get-scans-that-completed.md): This endpoint returns scans that completed.
- [Get Failed Scans](https://docs.kondukto.io/reference/get-scans-that-failed.md): This endpoint returns scans that failed.
